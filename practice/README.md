# Practice projects

Building things is how the notes become real. Each folder is a starter design doc for a classic system design problem. Fill it in before writing code.

## Order (easiest → hardest)

1. [URL shortener](01-url-shortener/design-doc.md) — hashing, caching, simple DB schema.
2. [Rate limiter](02-rate-limiter/design-doc.md) — algorithms, distributed counters.
3. [Pastebin / file share](03-pastebin/design-doc.md) — object storage, signed URLs.
4. [Chat service](04-chat-service/design-doc.md) — WebSockets, fan-out, presence.
5. [News feed](05-news-feed/design-doc.md) — push vs pull, ranking, caching.
6. [Job scheduler](06-job-scheduler/design-doc.md) — leader election, idempotency, retries.
7. [Mini Kafka](07-mini-kafka/design-doc.md) — log-structured storage, partitions, replication.
